# Gestión del proyecto

El trabajo se organiza con un tablero Trello:

https://trello.com/b/MIkiXKvw/mi-tablero-de-trello

## Columnas

- Backlog: ideas y mejoras futuras.
- Todo: tareas listas para empezar.
- In Progress: tareas en desarrollo.
- Review: tareas que necesitan revisión o prueba.
- Done: tareas terminadas.

## Tarjetas sugeridas

- Configurar proyecto Vite con React y TypeScript.
- Configurar Tailwind CSS.
- Crear estructura de carpetas.
- Diseñar backend Express por capas.
- Crear endpoints REST de libros.
- Crear cliente API tipado.
- Crear contexto global de biblioteca.
- Crear componentes reutilizables.
- Crear rutas y página 404.
- Documentar API y arquitectura.
- Preparar despliegue en Vercel.

## Subtareas técnicas

Cada funcionalidad se divide en subtareas pequeñas: crear tipos, crear componente, conectar API, validar errores, probar manualmente y documentar.

## Flujo de avance

Las tarjetas empiezan en Backlog o Todo. Cuando se trabaja en ellas pasan a In Progress. Al terminar la implementación pasan a Review. Después de probarlas manualmente se mueven a Done.

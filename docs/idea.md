# Idea del proyecto

## Nombre

NextChapter

## Problema que resuelve

Muchas personas guardan recomendaciones de libros en notas sueltas, mensajes o memoria. Esto hace difícil saber qué libros están pendientes, cuáles se están leyendo y cuáles ya se terminaron.

NextChapter resuelve este problema centralizando una biblioteca personal sencilla y clara.

## Usuario objetivo

El usuario objetivo es una persona lectora, estudiante o aficionada a los libros que quiere organizar sus lecturas sin usar una herramienta compleja.

## Funcionalidades principales

- Listar libros de la biblioteca.
- Añadir libros con título, autor, estado, valoración y notas.
- Editar libros existentes.
- Eliminar libros.
- Buscar por título o autor.
- Filtrar por estado de lectura.
- Ver estadísticas rápidas.

## Funcionalidades opcionales

- Drag and drop para cambiar estado.
- Etiquetas por género.
- Favoritos.
- Exportación a CSV.
- Tests automáticos.
- Documentación OpenAPI.

## Mejoras futuras

- Autenticación de usuarios.
- Base de datos real.
- Integración con una API externa de libros.
- Recomendaciones personalizadas.
- Modo oscuro.
